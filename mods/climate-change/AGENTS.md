# Climate Change instructions

Apply root instructions and shared requirements. This is a research-stage mod;
do not imply that scaffolding or earlier discussion is an implemented release.
Preserve the user's one-direction-per-game requirement: warming or cooling.

Keep confirmed requests separate from assistant proposals in `docs/REQUIREMENTS.md`.
Validate tile property changes and native visual refresh separately. Before any
land/water conversion experiment, define how affected cities, resources,
improvements and units are protected; use a disposable test game.

Future APIs must account for farm connectivity/yields and Terrain exposure without
silently making a companion mandatory. Keep experiments and support tools outside
the runtime package. Record methods, observed results and remaining uncertainty.
