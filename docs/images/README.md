# Player-guide image provenance

The guides and collection README reuse existing original project images without
altering them. The shared [Living Map identity](../../shared/art/collection-identity/README.md)
provides the collection masthead, with preserved SVG sources and reusable exports.
A small original SVG diagram illustrates Climate Change's confirmed warming-or-cooling
direction; it is documentation, not proposed game artwork.

| Local image | Original location | Meaning |
| --- | --- | --- |
| `caravansary-preview.jpg` | `output/models/revised-v2/RT_Caravansary_Ancient-preview.jpg` | Render of the approved source model; native integration pending |
| `motorized-caravan-preview.jpg` | `output/models/revised-v2/RT_MotorizedCaravan-preview.jpg` | Render of the approved source model; native integration pending |
| `climate-direction.svg` | Authored directly as an SVG for the collection README | Diagram of the confirmed one-direction-per-game requirement; no gameplay or visual-asset claim |

These two unchanged previews are versioned here so player-guide images work in a
fresh checkout. The guides also reference versioned originals directly in
`shared/art/`: Ministry completion art, the Resource Outposts emblem, a Medieval
Outpost concept, and the Irrigated Farm v6 concept. Their existing approval records
remain authoritative. Concept/model approval is not in-game screenshot evidence.

Keep visible captions beside images. Replace previews with real gameplay images
when available and verified, while preserving source provenance. Do not embed
ignored output files, local absolute paths, proprietary reference extracts or
unapproved alternatives in the player guides.
