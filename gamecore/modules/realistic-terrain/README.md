# Terrain native module

Implementation boundary: [native trade contract](../../../mods/realistic-terrain/docs/NATIVE-TRADE-CONTRACT.md).
The full contract is not implemented by core 0.1.0; no Terrain simulation
capability is registered. Existing Terrain Lua remains authoritative. Native
trade must own genuine connections, eligibility, paths, yields and plunder, with
its own validated save contract before content changes backend.
