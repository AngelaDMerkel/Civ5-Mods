# Original art and approvals

- [Collection identity](collection-identity/README.md): the current Living Map
  masthead, icon and wordmark, unchanged reviewed sources, reusable exports and
  the user's scoped directional preference. Documentation assets only.

- `terrain-icons-round-3/`: selected original sheets/images, prompts, crop choices
  and DDS export hashes. This is now the authoritative input to `tools/export_art.py`.
- `rt-models/approved.json`: exact hashes for the nine approved Terrain source
  model variants. Existing approval scope includes the Irrigation Works building;
  preserve that record rather than splitting its history during a directory move.
- `outpost-era-concepts-v1/`: original options, selected era designs, materials,
  prompts, comparison records and user approval of the revised source meshes.
- `irrigated-farm/`: original approved v6 tile concept and prompts, with a scoped
  approval record. This does not approve every subsequent mesh revision.

Original images are preserved byte-for-byte. Large reproducible meshes, ZIPs and
review renders remain in ignored `output/` and `dist/`. Stock game reference art
is excluded. Follow [art requirements](../requirements/ART.md) when adding or
changing assets, and keep existing approval hashes intact.
