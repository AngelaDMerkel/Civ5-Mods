# Irrigated Farm concept

The original `irrigated-farm-adjacency-v6.png` and its prompt/notes files were
copied unchanged from the local concept output into this versioned directory.
The Irrigated Farm chat recorded the user's approval before mesh production:
“This is approved. Can you design the mesh for these tiles, making sure you
remain as close to the real Civ5 style as possible”.

The approval covers that concept. The user later requested greater mesh detail
and density; current mesh refinement and native terrain fitting have separate
acceptance. See `approved.json` for source integrity and scope.

On 2026-10-09 the user selected native Farm and Incan Terrace Farm artwork with
readable irrigation additions as the **preferred approach**. See
[native-overlay-study/direction-selection.json](native-overlay-study/direction-selection.json)
for the exact confirmation, referenced study hash and approval scope. This
supersedes the replacement-field approach while preserving the v6 concept and
its original approval record. Final mesh acceptance and native validation remain
separate.
