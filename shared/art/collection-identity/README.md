# Collection identity — Living Map

The user identified **E — Living Map** as closer to the intended direction on
2026-10-09. This is the collection's current visual direction. The exact comment,
scope and source/export hashes are retained in [selection.json](selection.json).

The source artwork is unchanged from the reviewed E proposal. Its hex tile brings
together a mountain, river and cultivated land using the
[verified WSDLC palette](../../references/branding/README.md). The icon has no
face or initial. The personality brief is design guidance, not public copy.

The exported SVGs contain vector glyphs, so they do not depend on the viewer's
fonts. The icon and wordmark have transparent canvases; the masthead has the WSDLC
cream background. The `source/` SVGs retain editable text and the original
Menlo/DejaVu Sans Mono font stack. Original geometry was authored directly as SVG;
no image-generation prompt or raster crop was used.

The README references the masthead directly. These are documentation/collection
assets, not game assets. Genuine Civ V reference extracts and unselected proposals
remain in ignored local review output and are excluded from playable packages.
