# Shared resource instructions

Apply the root instructions. Keep common requirements separate from per-mod
gameplay rules. Record whether a statement is a user requirement, a measured
implementation fact, a proposal or a pending experiment.

Preserve approved original art and recorded hashes. New approval records must
have direct user evidence and a narrow scope; do not broaden an existing approval.
Treat stock game screenshots/textures as local references, excluded from Git and
release bundles. Requirements and reference indexes should link to authoritative
files rather than duplicate them.
